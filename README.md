# Muestras web Grupo VL

Espejo público y de solo lectura de las maquetas de rediseño de SUAT, Tresur, Maquinfra y Grupo VL. Se genera a mano desde `TToLabs/grupovl-marketing` (privado), que es la fuente de verdad. Aquí nunca se edita directo.

- `familia-a/`: la página actual y la propuesta, lado a lado.
- `familia-b/`: plantilla formal común con selector de empresa.
- `familia-c/`: una página B2B propia por empresa.

Son maquetas de trabajo, no los sitios oficiales. Llevan `noindex` y `robots.txt` para que los buscadores no las indexen. Los formularios no envían nada.
